# 更好的车辆标签

《极限竞速：地平线 6》的中文 Windows 车库工具。自动读取本机车库和车辆缩略图，按单车设置赛事类型、性能倾向和强度，并在游戏的原生车卡上显示彩色标签。

[**下载 Windows 版（BetterCarTage.exe）**](https://github.com/KasumiAimi/Forza-better-cartage/releases/latest/download/BetterCarTage.exe)

适用 Windows x64。下载为压缩打包的单个 EXE，双击即可使用，无需安装或另装 .NET。重复打开时会切回已经打开的编辑器窗口。

## 使用前请知悉

> 这是玩家制作的非官方工具。点击「应用到游戏」会在游戏安装目录写入车卡界面覆盖文件，属于类似 Mod 的游戏文件修改，存在被封号的可能。无法接受风险，请勿使用。使用本工具的风险由使用者自行承担，作者不对因此产生的账号处罚、存档问题或其他损失负责。

## 使用方法

1. 打开 `BetterCarTage.exe`，工具会自动查找本机存档并列出车库车辆。检测到多个档案时可在右上角切换。自动查找不到时，可手动选择整份 `C_ProfileData` 文件。
2. 按制造商、车辆等级、车型名、收藏和三类标签组合筛选。每类标签可选全部、具体标签或「未标记」。「清空筛选」会清除所有筛选和搜索词，回到完整车库的第一页。游戏内车库或收藏有变化时，点击「刷新车库」同步。
3. 选中车辆后，左栏会显示车辆缩略图、已装轮胎、马力（hp）、车重（kg）和驱动形式，也可以在这里设置标签。漂移胎按安装的配方识别。每台车独立保存，选择「未标记」可清除对应类别。
4. 点击「我的车辆」右侧的「标签管理」，可添加、改名、改色或删除标签。改名和改色后，车辆仍关联原标签。删除后，所有车库档案中的相关车辆都会恢复为该类未标记。
5. 要在游戏车库和赛前选车界面显示新的标签或颜色，请先退出 FH6，再点击「应用到游戏」，然后重新启动游戏。
6. 左侧「更新器」显示本地版本、GitHub 正式发布版本和发布记录。程序启动时会检查更新。发现可安装的新版时，点击「下载更新并重启」，程序会校验下载后替换当前可执行文件。

| 标签 | 默认选项 | 名称长度上限 |
| --- | --- | --- |
| 赛事类型 | 公路、拉力、越野、直线加速、漂移 | 4 个汉字或 8 个英文字母 |
| 性能倾向 | 操控、均衡、动力 | 3 个汉字或 6 个英文字母 |
| 强度 | Overpower、META、T1、T2、T3、TOY | 5 个汉字或 10 个英文字母 |

混合输入时，ASCII 字符计 1 个单位，其他字符计 2 个单位。

缩略图优先读取本机车库缓存。缺少缓存时会显示原厂车型图，外观可能与当前涂装不同。

## 存档与游戏文件

- 车辆标签保存在 `%LOCALAPPDATA%\FH6GarageEditor\tags`，自定义标签配置保存在同级的 `tag-catalog.json`。游戏存档和收藏仅用于读取。
- 「应用到游戏」从原版 `media\UI.zip` 读取车卡模板，并生成 `mediapc\UI\Resources\Anthem\Shared_CarSelect.xaml`。退出游戏后，移走本工具生成的覆盖文件即可撤下游戏内标签。
- Steam 和微软商店／Xbox App 版都可以使用「刷新车库」自动查找存档。若未找到，可用「选择存档」手动打开对应账户的 `C_ProfileData` 文件。Windows 上可先查看 `C:\XboxGames\GameSave\pgs`。
- 工具会自动查找 Steam 和 Xbox App 的游戏安装目录。游戏装在其他位置，或电脑同时安装了两版时，可点击右下角「游戏目录」，选择包含 `forzahorizon6.exe` 的文件夹。车型资料和徽标都使用选中的目录。
